# Examples

每个子目录是一个可运行示例：

```bash
cd examples/convert && go run .
cd examples/json && go run .
cd examples/algo && go run .
# ...
```

| 目录 | 对应包 |
|------|--------|
| `convert` | 类型转换 |
| `json` | JSON |
| `gerror` | 错误栈 |
| `gtime` | 时间 |
| `mr` | MapReduce |
| `collection` | 切片工具 |
| `retry` | 重试 |
| `safego` | 安全 goroutine |
| `hashx` | 哈希 |
| `cryptox` | 加解密 / HMAC / 口令 |
| `randx` | 随机数 |
| `empty` | 空值判断 |
| `judge` | 字符串判定 |
| `regex` | 正则 |
| `gbinary` | 二进制编解码 |
| `structutil` | 结构体 tag |
| `algo` | 常用算法 |
